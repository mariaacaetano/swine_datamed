# Atualização das fontes CSV em 13/11/2026

Os seis arquivos de `base_data` foram sincronizados nas branches `main` e
`engines`. A diferença entre as branches continua sendo o painel comparativo
e a API de comparação, preservados em `engines`.

A importação em banco temporário vazio produziu:

| Entidade | Quantidade |
|---|---:|
| Enfermidades | 112 |
| Sintomas, incluindo o marcador documental | 80 |
| Variáveis | 52 |
| Fármacos | 68 |
| Vacinas | 4 |
| Indicações | 86 |

Foram acrescentados 54 fármacos; 43 dos registros novos possuem apenas nome e
identificador na fonte. Os campos ausentes são preservados sem preenchimento
automático. As indicações existentes continuam produzindo 29 vínculos resolvidos
entre fármaco e enfermidade. A ampliação do catálogo não cria novas indicações.

Os perfis de associação entre sintomas e enfermidades foram preservados. Houve
padronização dos tipos de 22 enfermidades, atualização das opções de variáveis e
renomeação de `Idade` para `Idade (dias)` e de `Fase reprodutiva` para
`Fase produtiva` no cadastro de variáveis. A versão semântica da base passou de
`d99efb8ab365d4540c97a3246a6e52d64aed05ae026d018828777c94dfb5de43` para
`2d990ba429f907f2c2e79f587fc3407f27b2d5944bbc4873cf46ec4db07f407b`.

Esta atualização versiona as fontes e ajusta as contagens do teste de importação.
Não substitui automaticamente o banco em uso, os datasets gerados ou os modelos
treinados. Relatórios anteriores descrevem os dados identificados por seus hashes
e não foram recalculados para esta revisão. Uma nova geração ou treinamento deve
considerar os nomes e as definições atualizados das variáveis, preservando os
artefatos históricos para reprodução dos ensaios.
